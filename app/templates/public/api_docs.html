REST API Reference

Universal SMM API v2 specification for order routing, balance checks, and status webhooks.

Protocol & Endpoint
Method POST
Format application/json
Auth Header / Key key parameter
Path /api/v2
POST action: services
Fetch active packages & limits

Returns an array of all active services, rates per 1,000, and minimum/maximum constraints.

// Payload Parameters

key: <your_api_key>

action: "services"

// Sample 200 OK Response

[
  {
    "service": 1,
    "name": "Instagram Followers HQ",
    "type": "Default",
    "category": "Instagram Followers",
    "rate": "45.00",
    "min": 100,
    "max": 10000,
    "refill": true,
    "cancel": false
  }
]
POST action: add
Dispatch new campaign

Debits the user wallet in real time and submits the campaign to background routing engines.

// Payload Parameters

key: <your_api_key>

action: "add"

service: 1

link: "https://instagram.com/p/sample"

quantity: 1000

// Response

{ "order": 104 }
POST action: status
Check order progress

Polls status for a single order ID or comma-separated batch list.

// Sample Single Order Response

  "start_count": "1200",
  "status": "Completed",
  "remains": "0",
  "currency": "INR"
}
